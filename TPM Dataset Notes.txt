TPM Dataset Construction & Filtering Scripts — Notes

1. TPM Builder Script (catheter_two_process_daily_raw.csv)
Constructs the full Two-Process Model (TPM) dataset following Makic et al.

Builds daily risk-set rows for both catheter_in (days with catheter) and catheter_out (days after removal until reinsertion or discharge).

Preserves duration dependence via day_index in both processes.

Defines next-day outcome labels (removal, reinsertion, CAUTI).

Aggregates EHR chartevents into daily covariates.
This file is the immutable source of truth for all downstream modelling.

2. Coverage Analysis Script (covariate_selection_summary.csv)
Determines which covariates are eligible for modelling based on data availability.

Evaluates mean covariates only (itemid_<id>__mean).

Retains itemids that appear in ≥5% of TPM patient-days and ≥10% of catheterised stays.

Outputs a retain/drop decision per itemid.
This script performs availability filtering only, not modelling.

3. Covariate Filtering Script (catheter_two_process_daily_filtered.csv) — KEEP
Applies covariate selection without altering TPM structure.

Keeps all TPM rows (both processes, all days).

Retains only itemids marked retain in the coverage summary.

Keeps only selected statistics (e.g. mean).
This is the correct starting dataset for all TPM-based modelling and extensions.
